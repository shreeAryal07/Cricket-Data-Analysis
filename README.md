# 🏏 Cricket Data Analysis Using Python

## 📌 Project Overview
This is my beginner-level Data Analysis project using Python. The project explores and visualizes cricket statistics of popular international cricketers to compare their performances and identify useful insights through charts.

## 🎯 Project Objectives
- Compare total runs scored by different cricket players.
- Analyze and compare players' batting averages.
- Visualize centuries scored by each player.
- Understand the distribution of players' total runs.
- Practice data visualization using Python.

## 🛠️ Tools & Technologies
- **Python** – Data analysis and visualization
- **Matplotlib** – Creating charts and graphs
- **VS Code** – Writing and running Python code
- **Git & GitHub** – Version control and project sharing

## 📊 Visualizations
This project includes the following visualizations:

1. Bar Chart – Comparing players' total runs.
2. Pie Chart – Showing each player's share of total runs.
3. Line Chart – Comparing batting averages.
4. Histogram – Understanding the distribution of total runs.
5. Bar Chart – Comparing centuries scored by players.

## 🚀 How to Run This Project

1. Clone this repository:
   ```bash
   git clone https://github.com/shreeAryal07/Cricket-Data-Analysis.git
   ```
2. Open the project folder in VS Code.
3. Install Matplotlib:
   ```bash
   pip install matplotlib
   ```
4. Run the Python file:
   ```bash
   python Analysis.py
   ```
